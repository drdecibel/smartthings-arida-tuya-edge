## Technical foundations

The Tuya protocol implementation follows [tinytuya](https://github.com/jasonacox/tinytuya) and reuses
MIT-licensed code from [ST-SmartHome/smartthings-drivers](https://github.com/ST-SmartHome/smartthings-drivers)
and [lua-lockbox](https://github.com/somesocks/lua-lockbox). The Arida data point mapping comes from
[make-all/tuya-local](https://github.com/make-all/tuya-local). See the acknowledgements in [README.md](README.md).
